# Responsible Disclosure

This repository has been claimed as part of a responsible 
security disclosure reported to Discourse via HackerOne.

**Vulnerability:** RepoJacking in official Discourse plugin 
registry (discourse/all-the-plugins/third-party.txt)

The original owner renamed their GitHub username (Toxuru → evgip), 
leaving this namespace freely registerable. This demonstrates that 
any Discourse admin installing this plugin via git clone would 
receive attacker-controlled code.

**NO malicious code has been placed here.**
